# Odoo Scenario Lab

اختبر أي دالة في موديل أودو بضغطة واحدة. الإضافة تولّد سيناريوهات حقيقية من بيانات قاعدتك، تشغّلها بأمان، ثم تعطيك تقريرًا يوضح **أين** حدث الخطأ و**لماذا** و**كيف تصلحه**.

> [English](README.md)

## ماذا تكتشف؟
- `Expected singleton` عند تشغيل الدالة على أكثر من سجل.
- استخدام حقل فارغ (`False`) كأنه سجل أو نص أو تاريخ.
- القسمة على صفر والعمليات الحسابية على قيم فارغة.
- مفاتيح غير موجودة في `vals` داخل `create` و `write`.
- حقول محسوبة لا تُسند لها قيمة في كل الحالات.
- أخطاء الصلاحيات عند التنفيذ بمستخدم عادي.
- حقول موجودة في الكود وغير موجودة في قاعدة البيانات (الموديول يحتاج تحديث).

## طريقة الاستخدام
1. نفّذ الأمر **Odoo Lab: إعداد الاتصال بأودو** واختر مجلد أودو وبايثون وملف `odoo.conf` وقاعدة البيانات.
2. اضغط **▶ اختبر السيناريوهات** فوق أي دالة، أو كليك يمين ← «اختبار سيناريوهات الدالة»، أو `Ctrl+Alt+T`.
3. يظهر التقرير بجانب الكود، وتُميَّز أسطر الأخطاء باللون الأحمر.

## السيناريوهات
| نوع الدالة | ما يتم تجربته |
|---|---|
| زر / إجراء | سجل واحد، عدة سجلات، بدون سجلات، تفريغ كل حقل مستخدم، قيم Selection، السجلات المرتبطة الفارغة، مستخدم عادي |
| `@api.depends` | نفس ما سبق على نسخة مؤقتة من السجل |
| `@api.onchange` | سجل موجود، سجل جديد فارغ، تفريغ الحقول |
| `@api.constrains` | القيم الصفرية والسالبة والفارغة |
| `create` | بيانات كاملة، `{}`، إنشاء متعدد، حذف كل مفتاح أو جعله `False` |
| `write` | تعديل عدة سجلات معًا وقيم مختلفة لكل مفتاح |

## الأمان
- كل سيناريو يعمل داخل `SAVEPOINT` ويُلغى بالكامل، ولا يُحفظ أي شيء في قاعدة البيانات.
- يتم تجاهل `cr.commit()` ومنع إرسال البريد والطلبات الخارجية أثناء الاختبار.
- ترفض الإضافة افتراضيًا قواعد البيانات التي يحتوي اسمها `prod` أو `live`.
- مع ذلك: **استخدم نسخة تجريبية من قاعدة البيانات دائمًا.**

## المتطلبات
- أودو 14 أو أحدث مثبت على جهازك (بدون Docker في هذا الإصدار). تم اختباره على 17 و 19.
- PostgreSQL يعمل، وقاعدة بيانات فيها الموديول مثبت.
- الموديول محدَّث بعد إضافة حقول جديدة (`-u اسم_الموديول`).

## الإعدادات
| الإعداد | الوصف |
|---|---|
| `odooLab.pythonPath` | بايثون الذي ثُبّتت فيه متطلبات أودو |
| `odooLab.odooPath` | مجلد أودو الذي يحتوي `odoo-bin` |
| `odooLab.configFile` | ملف `odoo.conf` |
| `odooLab.database` | قاعدة البيانات (الافتراضي `db_name` من الملف) |
| `odooLab.runAsUser` | المستخدم المنفّذ (الافتراضي admin) |
| `odooLab.timeoutSeconds` | مهلة كل سيناريو |
| `odooLab.maxScenarios` | الحد الأقصى للسيناريوهات |
| `odooLab.allowProductionDatabase` | السماح بقواعد الإنتاج |
| `odooLab.enableCodeLens` | إظهار زر الاختبار فوق الدوال |
| `odooLab.language` | لغة التقارير: `auto` أو `en` أو `ar` |
